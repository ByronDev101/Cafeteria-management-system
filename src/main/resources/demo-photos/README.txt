Demo photos for the "dev" profile (optional)
============================================
Put JPEG or PNG photos here, named after the menu item in lower case with dashes, for example:

  chicken-and-rice.jpg
  beef-stew-with-ugali.jpg
  vegetable-pilau.jpg
  tea.jpg
  fresh-juice.jpg
  soda.jpg
  samosa.jpg
  chips.jpg
  mandazi.jpg

When the app starts in the dev profile, every item that has no photo yet picks up the matching file.
Only use photos you own or that have a licence allowing this use.
Managers can also upload photos on the Edit item page, which is how it works in real use.
